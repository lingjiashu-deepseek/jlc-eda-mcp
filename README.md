# jlc-eda-mcp

面向 **嘉立创EDA专业版（EasyEDA Pro / LCEDA Pro）** 的 MCP（Model Context Protocol）服务端：把工程、原理图、PCB 与制造文件能力，以类型化工具的形式暴露给 AI 编程助手。

> **状态：初始化种子仓库。** 目前只有项目说明、路线图与工具清单，还没有可运行实现。

## 要解决的问题

嘉立创EDA专业版把设计数据保存在本地工程文件里（`.epro2` / `.epru`），AI 助手很难直接读取工程结构，更难安全地改动它。
本项目把「读工程、查连接、跑检查、导制造文件」这些操作封装成一组边界清晰的 MCP 工具，让助手在明确的授权范围内工作，而不是靠截图和猜测。

## 计划提供的能力

- **工程**：列出 / 打开工程，读取页面与标题栏。
- **原理图**：元件、网络、连接查询，网表导出。
- **PCB**：板框、叠层、器件与网络查询，DRC 报告。
- **制造**：BOM、Gerber、CPL 导出。
- **安全**：写操作默认 dry-run，显式确认后才落盘。

## 设计原则

1. **只读优先。** 能只读完成的事情不引入写操作。
2. **写操作显式授权。** dry-run 给出将发生的变化，确认后执行。
3. **对齐官方 API。** 不绕过 EasyEDA Pro 的界面契约，不模拟点击。
4. **失败可操作。** 每个错误都说明缺什么、下一步该做什么。
